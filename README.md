# 体重白皮书

体重是读数，行为是旋钮。从能量平衡讲到目标设定、训练执行和测量。

**线上 →** [body.fim.ai](https://body.fim.ai)

**本地预览 →** `pnpm install && pnpm dev`（http://localhost:5195）

## 主线

减脂期用目标体重，维持期用目标行为。前者有终点，后者没有。

## 大纲（7 部分 · 14 节 + 附录）

1. **机制** — 能量平衡与自然体重 · 食欲代偿
2. **目标** — 目标体重怎么定 · 腹肌 · 减脂期与维持期
3. **杠杆** — 饮食、抗阻、日常活动、有氧、睡眠的比重
4. **执行** — 居家抗阻训练 · 忙的时候怎么练 · 步数与日常活动
5. **跑步入门** — 跑鞋的结构 · 跑姿与加量
6. **测量** — 秤的读数与噪音 · 身体感
7. **吃** — 日常吃法

附录：名词表 · 和常见说法不一样的地方

带计算器的章节：01 自然体重落点 · 03 推荐目标体重 · 06 蛋白质 · 09 步数 · 12 7 日均值 · 14 包装标签换算

章节清单的唯一事实来源是 `src/chapters.ts`。正文在 `content/*.md`，以 `_` 开头的文件不进仓库、不进构建。

# 居家抗阻训练

## 肌肉看的是负荷有没有往上走

肌肉增长的条件是**渐进超负荷**：这次的负荷比上次多一点，多的可以是重量、次数或组数。这个条件和场地无关。健身房提供的是更大的重量范围和更多器械，不是增肌的前提。

对没有系统训练过的人，起步阶段自重加一副可调哑铃就能持续加负荷。本书估计这段时间在 6 到 12 个月之间，取决于起点和进步速度，没有研究直接测过这个数。

## 轻重量也能练，条件是练到接近力竭

居家器械的上限比健身房低，常见的担心是「重量不够就长不了肌肉」。

有研究把二十多项实验放在一起，比较轻重量和大重量训练。分界是 1RM（一次最多能举起的重量）的 60%。选进来的实验都要求每一组做到力竭（再也做不动一次），至少练 6 周。结果：

- **肌肉体积的增长，两种负荷相近。**
- **1RM 最大力量，大重量组涨得更多**；等长力量（用力但关节不动，比如推墙）两组没有差别。

所以在居家条件下，用较轻的哑铃做更多次数，对肌肉体积够用，前提是每组做到接近做不动为止。代价是最大力量涨得慢一些。对以体成分为目标的人，这个代价可以接受。

注意这些研究的组都做到了力竭。下文计划里写的「力竭前 2 次」比研究条件保守，是为了动作质量和恢复，属于本书的取舍。

## 装备

| 装备 | 用途 | 备注 |
|---|---|---|
| 可调哑铃（单只 5–25 kg） | 下肢、推、拉的主要负荷 | 选能小幅加重的型号 |
| 弹力带 | 下拉、面拉、辅助引体 | 准备 2–3 种阻力 |
| 门框引体杆（可选） | 引体向上 | 先确认门框能承重 |

一块瑜伽垫就是全部场地需求。

推荐可调哑铃，是因为同一次训练里各动作需要的重量差得多：侧平举可能 5 kg，划船要 15–20 kg，高脚杯深蹲更重；力量涨了还要继续加。用固定哑铃覆盖这个范围，要买十来对再配一个架子。可调哑铃一对就够，代价有三：

- **长度按最大重量算。** 调到 5 kg 也一样长，做飞鸟、侧平举、推肩时不如固定哑铃顺手。
- **不能摔。** 内部有卡扣，放下时要慢。
- **档位固定。** 想要的重量正好在两档之间时，只能用次数补。

### 插片式哑铃怎么配档

插片式可调哑铃由把手、螺杆、铃片和卡扣组成。拆光所有活动铃片后剩下的是**裸重**；有的型号最内侧有一对不可拆的片，裸重要把它们算进去。买回来先确认三件事：裸重多少、每种铃片几片、每片多重。

两侧要装得一样重。哑铃一头沉，手腕就得额外对抗它往一边转，飞鸟、侧平举、弯举这类靠手腕控制方向的动作尤其明显。所以能用的档位是「两侧对称」能凑出来的那些：

- **只有一种铃片时**，每次只能两侧各加一片，单只哑铃一跳就是两片的重量。2 kg 的片一跳 4 kg。
- **配了小片时**，大小片组合起来可以缩小跳档。以一款常见规格为例：裸重 6 kg，每只配 6 片 2 kg、2 片 1 kg，范围 6–20 kg：

| 单只重量 | 每侧装 |
|---|---|
| 6 kg | 不加片 |
| 8 kg | 1 kg × 1 |
| 10 kg | 2 kg × 1 |
| 12 kg | 2 kg × 1 + 1 kg × 1 |
| 14 kg | 2 kg × 2 |
| 16 kg | 2 kg × 2 + 1 kg × 1 |
| 18 kg | 2 kg × 3 |
| 20 kg | 2 kg × 3 + 1 kg × 1 |

这款每档都是 +2 kg。商家标的「最小增量」有时是靠一侧多装一片得到的，推、划船、深蹲这类动作偏一片影响不大，上面说的三类动作不要这样用。

每组开始前检查卡扣拧紧，卧推、肩推这种哑铃在脸上方的动作尤其要查。

只想要两三个重量的人，买几对固定哑铃也能练；杠铃加深蹲架加重空间最大，但需要整块场地，更适合认真练了一两年之后。

## 一周三练：A / B / C

每周三次，按 A、B、C 轮换，两次之间至少隔一天。每次约 35–45 分钟。

| 训练日 | 动作 | 组 × 次 |
|---|---|---|
| A 下肢 + 核心 | 高脚杯深蹲 | 3 × 10–12 |
| | 保加利亚分腿蹲 | 3 × 8 / 侧 |
| | 臀桥 | 3 × 12 |
| | 哑铃罗马尼亚硬拉 | 3 × 10 |
| | 平板支撑 | 3 × 45 s |
| B 推 | 俯卧撑 | 3 × 力竭前 2 次 |
| | 哑铃肩推 | 3 × 10 |
| | 地板卧推 | 3 × 10 |
| | 侧平举 | 3 × 12 |
| | 臂屈伸 | 3 × 12 |
| C 拉 | 引体向上 / 弹力带下拉 | 3 × 力竭前 2 次 |
| | 单臂划船 | 3 × 10 / 侧 |
| | 面拉 | 3 × 15 |
| | 弯举 | 3 × 12 |
| | 农夫行走 | 3 组 |

## 怎么加量

起始重量这样选：第一周每个动作用一个偏轻的重量试做，最后一组做完时，感觉还能再做 2 次左右，就是合适的起点。宁可轻一档，前两周的主要任务是熟悉动作，不是测试上限。

之后的规则只有一条：**每次记下每个动作的重量和次数，下次至少一项比上次多。**

具体做法用「双重递进」：先在同一重量下把次数加到区间上限（比如深蹲三组都做到 12 次），下一次换更重的哑铃，次数退回区间下限，再往上加。俯卧撑这类自重动作，次数加到 20 次以上后改用更难的变式，比如脚垫高。

### 起步重量按动作分

同一副哑铃，各动作的起步重量差得多：小肌群单关节动作用得最轻，大肌群多关节动作最重。下表是本书给没有系统训练过的成年人的参考起点，按单只哑铃算。每个人力量不同、哑铃档位不同，以「最后一组还剩 2 次左右余力」为准，取最接近的那一档。

| 动作 | 主要肌群 | 辅助肌群 | 参考起点（单只） | 加重 |
|---|---|---|---|---|
| 侧平举 | 三角肌中束 | 斜方肌上部 | 4–6 kg | 跳档对它比例最大，主要靠次数和慢放 |
| 飞鸟 | 胸大肌 | 三角肌前束 | 4–6 kg | 稳做 15 次以上再加 |
| 弯举 | 肱二头肌 | 肱肌、前臂屈肌 | 6–8 kg | 每档加 |
| 颈后臂屈伸（双手握一只） | 肱三头肌，以长头为主 | — | 8–10 kg | 每档加 |
| 肩推 | 三角肌前束、中束 | 肱三头肌、斜方肌上部 | 8 kg 左右 | 每档加 |
| 卧推 | 胸大肌 | 三角肌前束、肱三头肌 | 8–10 kg | 每档加 |
| 单臂划船 | 背阔肌、菱形肌 | 斜方肌中下部、三角肌后束、肱二头肌 | 10–12 kg | 每档加，涨得最快的动作之一 |
| 高脚杯深蹲（抱一只） | 股四头肌、臀大肌 | 内收肌、核心 | 12–14 kg | 抱一只到顶后，改双手各提一只 |
| 罗马尼亚硬拉（双手各一只） | 腘绳肌、臀大肌 | 竖脊肌、握力 | 10–14 kg | 每档加 |

小重量段的一档在比例上很大：6 kg 加到 8 kg 是 +33%，杠铃加 2.5 kg 片很少有这么大的跳跃。所以侧平举、飞鸟这类动作的次数上限放宽到 15–20 次，做满再加；加重后次数掉回 8 次上下是正常的。以前的一对轻哑铃不用扔，可以用来热身，或者一组做不动后换轻的再补几次。

重量上来以后，同一块肌肉每周练 2–3 次、中间至少隔一天，上面的 A / B / C 轮换就是按这个排的。

判断有没有在进步，看记录本，不看镜子和体重。一个动作连续三四次没有任何一项上涨，先查睡眠和饮食，再考虑换动作。

## 新手起步：一对轻哑铃和一张凳

很多人刚开始时家里只有一对 5 kg 左右的哑铃和一张能调角度的凳子。这套器材练手臂和肩够用，练腿和背偏轻，要靠下面的办法加难度。以下方案是本书的建议。

**分三个阶段走：**

| 阶段 | 时间 | 做法 |
|---|---|---|
| 学动作 | 第 1–2 周 | 每周 2–3 次，每个动作 2 组，每组做完还能再做 3–4 次。录侧面视频看动作 |
| 加到 3 组 | 第 3–6 周 | 每周 3 次，每个动作 3 组，每组做到只剩 1–2 次的余力。记下次数，下次至少多做一次 |
| 加难度 | 第 7 周起 | 次数到了区间上限，按下面的顺序加难度 |

**两套训练，A、B 轮换**（每周 3 次，比如这周 A-B-A，下周 B-A-B；每次约 30–40 分钟）：

| 训练日 | 动作 | 凳子怎么用 | 组 × 次 |
|---|---|---|---|
| A | 保加利亚分腿蹲 | 后脚搭在凳上，双手各拿一只哑铃 | 3 × 10–15 / 侧 |
| | 哑铃卧推 | 平躺在凳上 | 3 × 12–20 |
| | 单臂划船 | 一手一膝撑在凳上 | 3 × 15–20 / 侧 |
| | 臀桥 | 上背靠在凳边，哑铃放在髋部 | 3 × 15–20 |
| | 侧平举 | 不用凳 | 2 × 15–20 |
| B | 深蹲 | 不用凳，双手各拿一只哑铃垂在身侧 | 3 × 15–25 |
| | 俯卧撑 | 做不了标准的，就双手扶凳做 | 3 × 力竭前 2 次 |
| | 哑铃罗马尼亚硬拉 | 不用凳，熟练后改单腿 | 3 × 12–20 |
| | 上斜飞鸟 | 凳面调成斜的 | 3 × 12–15 |
| | 平板支撑 | 不用凳 | 3 × 30–60 秒 |

**哑铃太轻时，按这个顺序加难度：**

1. **加次数。** 每组最多加到 25–30 次。
2. **放慢下放。** 每次用 3 秒放下，同样的重量会难很多。
3. **在最难的位置停一下。** 比如深蹲蹲到底停 1–2 秒。
4. **改成单侧动作。** 深蹲换成分腿蹲，硬拉换成单腿硬拉，一条腿承担原来两条腿的重量。
5. **换更重的哑铃。** 前四步都用完还嫌轻，就该买更重的了。腿和背通常最先不够，可以考虑上文的可调哑铃。

前三步的依据是上文的负荷研究：轻重量练到接近做不动，长肌肉的效果和大重量相近。

## 飞鸟练的是哪块肌肉

躺在凳上做飞鸟，看起来是把哑铃「抬起来」，常被理解成二头肌加胸肌一起出力。实际动作发生在肩关节，肘关节不动。

**动作是肩关节水平内收。** 手臂从两侧张开合拢到胸前，上臂在水平面上往身体中线扫。胸大肌从胸骨和锁骨出发，附着在肱骨上端前侧，收缩时把肱骨拉向中线，这是它的主要功能。躺着时重力向下，合拢的方向刚好是向上，所以看起来像「抬」。站着用绳索夹胸是同一个动作，只是阻力换成了水平方向。

| 肌肉 | 角色 | 做什么 |
|---|---|---|
| 胸大肌 | 主动肌 | 把上臂拉向中线 |
| 三角肌前束 | 协同肌 | 分担一部分水平内收 |
| 肱二头肌、肱肌 | 稳定肌 | 把肘固定在微屈角度，长度基本不变 |
| 肩袖、菱形肌、斜方肌中部 | 稳定肌 | 把肩胛骨收紧压在凳面上 |

做完二头肌明显发酸，通常是肘在中途越弯越多，动作变成了半个卧推或弯举。

**底部最难，顶部最轻。** 阻力力矩等于哑铃重量乘以哑铃到肩关节的水平距离。手臂张开时距离最远、力矩最大，胸大肌也处在拉长的位置；合拢到胸前正上方时，哑铃几乎在肩关节正上方，力矩接近零。所以哑铃飞鸟顶部不用完全合拢，停在哑铃到正上方之前就往回放，胸肌一直有负荷。

**底部别放太低。** 上臂放到大致和躯干平齐、胸部有明显拉伸感就够了。再往下，肩关节前侧和肩袖受力增大，是飞鸟最常见的受伤位置。手心相对或略朝脚都可以，不用刻意转手腕。

## 下放和拉长位置

一次完整的动作有两段：肌肉缩短着发力叫**向心**（卧推推起、弯举弯起），肌肉一边发力一边被拉长叫**离心**（下放）。

**两段都长肌肉。** 一项汇总了 15 项实验的荟萃分析里，只练离心的肌肉平均长了 10.0%，只练向心的长了 6.8%，差异没有达到统计显著（Schoenfeld 2017）。2025 年一项纳入 26 项实验的荟萃分析同样没有发现差别，证据等级为「很低」（Lopes da Silva 2025）。正常做动作两段都有，不需要专门挑一种练。实际要注意的是下放别随手丢下去，那会丢掉一半的刺激。

**酸痛和长肌肉是两回事。** 「肌肉撕裂再修复就长大」是常见说法。练完酸痛主要来自离心阶段的微损伤，但一项跟踪 10 周训练的研究发现：第一周损伤最重时，肌纤维蛋白合成虽然最高，和最终的肌肉增长没有关系；到第 3 周和第 10 周损伤减轻后，蛋白合成才和增长高度相关（Damas 2016）。同一个动作练几周后不怎么酸了，肌肉照样在长。

**拉长位置受力的动作，效果往往不差。** 几项对照实验比较了同一块肌肉在不同长度下受力：

- 颈后臂屈伸（手臂举过头顶，三头肌长头被拉长）和手臂垂在身侧的下压相比，练 12 周后整块三头肌体积多长了约 40%（+19.9% 对 +13.9%），而颈后组用的重量更轻（Maeo 2023）。
- 深蹲蹲得更深的一组，臀大肌和大腿内收肌长得更多；股四头肌两组相近（Kubo 2019）。

这类研究样本都不大，方向比较一致。它解释了为什么飞鸟顶部「歇着」仍是有效的胸肌动作：负荷集中在胸肌被拉长的底部。

**落到操作上：**

1. 推起、拉起用正常速度，下放用 2–3 秒。
2. 在拉长的位置停半秒到一秒，不借反弹起来。
3. 下放深度到有明显拉伸感为止。肌肉被拉长、负荷又最大的转折点，也是急性拉伤最常发生的位置。

## 限制

- **下肢的重量上限先到。** 腿部力量增长快，25 kg 的哑铃迟早会让深蹲和硬拉的次数涨到很高。按上面的研究，高次数仍能刺激肌肉，但每组时间变长、心肺先于腿部疲劳，训练效率下降。本书估计这发生在开始训练 8–12 个月后，届时可以换成单腿动作，或者考虑健身房。
- **最大力量涨得慢。** 原因见上文的负荷研究。
- **没有人纠正动作。** 可以用手机录侧面视频自查。

居家的好处在于门槛：不用通勤，不受营业时间和私教合同约束。训练能持续，比单次训练的质量更影响长期结果。忙的时候怎么保住这三次训练，见第 08 节。
